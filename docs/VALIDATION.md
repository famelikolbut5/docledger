# Проверки

Проверено 6 октября 2026 года.

## Автоматические

- Сборка TypeScript, интерфейса Vite и сервера внутри Docker проходит.
- Три интеграционные проверки API проходят с настоящей PostgreSQL 16.
- Приложение и база перезапущены: сохранённые записи не изменились.
- npm audit после обновления Express и Vite: 0 найденных уязвимостей.

Проверены создание и поиск документа, смена статуса, отсутствие дублей в истории при повторном запросе, архив, отклонение некорректных значений и CSV с защитой от формул.

## В браузере

Проверены форма создания, поиск, архив и изменение статуса. На ширине 1454 и 443 CSS-пикселя горизонтального переполнения нет. Снимки для портфолио сделаны в режиме `?preview`, который скрывает полосы прокрутки, сохраняя саму прокрутку.

## Границы

Проверки выполнены на локальной демобазе, не на инфраструктуре заказчика. Нагрузочные испытания, многопользовательская авторизация и внешние интеграции не входят в эту версию.
